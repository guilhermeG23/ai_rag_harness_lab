# Glossário

- **ACL:** lista que concede acesso a um recurso.
- **Chunk:** trecho de documento indexado separadamente.
- **DLQ:** fila de mensagens que falharam definitivamente.
- **Embedding:** vetor que representa significado aproximado de texto.
- **Guardrail:** regra aplicada ao redor do modelo.
- **Idempotência:** repetir uma operação sem duplicar efeito.
- **Inferência:** execução do modelo para gerar resultado.
- **Janela de contexto:** tokens que o modelo consegue considerar na chamada.
- **LLM:** modelo de linguagem de grande porte.
- **RAG:** recuperação de evidência adicionada ao prompt antes da geração.
- **Reranking:** reordenação dos resultados recuperados.
- **SSE:** streaming unidirecional de eventos HTTP.
- **Tenant:** cliente isolado logicamente no sistema.
- **Token:** unidade processada pelo modelo.
- **Trace:** caminho temporal de uma requisição por serviços.
- **Vector store:** armazenamento otimizado para busca por similaridade.
