# Visão geral

O harness transforma uma pergunta em uma resposta rastreável. Ele separa apresentação, orquestração, inferência, recuperação, persistência, mensageria e observabilidade para que cada responsabilidade possa ser estudada isoladamente.

Use `/chat` para a experiência comum e `/lab` para observar e administrar. O mesmo backend atende ambos, evitando regras de segurança divergentes. Consulte `STRUCT.md` para o diagrama completo.

Experimento: faça a mesma pergunta sem base, com uma base e novamente com cache; compare fontes e latência.
