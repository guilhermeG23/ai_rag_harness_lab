# Painel técnico

O `/lab` é a central administrativa do grupo: usuários, bases, documentos, jobs, cache e diagnóstico. Requer nível `admin` também na API; grupos globais são administrados no Identity Manager.

Os metadados do chat incluem modelo, bases, quantidade de fontes, tempo de recuperação, cache hit/miss, estimativas de tokens, primeiro token e duração. Eles explicam a execução sem expor raciocínio privado do modelo.
